Privacy

Last updated 5 October 2026

What this service does

header-scan is a free website scanner run as a personal project. You enter a web address, our server fetches that site (headers, the home page, a few well-known files, TLS and DNS information) and returns a graded report to you.

What is processed

  • The address you enter (or the host name for owner verification). It is used to run the scan and is not stored.
  • Your IP address. The server keeps it in memory for one to two minutes to limit how many scans one visitor can start, and to cap parallel scans. It is not written to disk.
  • DNS lookups. To check DNSSEC, the host name of the site you scan is sent from our backend to Cloudflare's public DNS-over-HTTPS resolver (cloudflare-dns.com). Your own IP address is not sent. Other DNS lookups use the backend's normal resolver.
  • The scan result. It is sent back to your browser and is not stored on the server. The Copy and Download buttons work locally in your browser.

What is not collected

  • No cookies, no local storage, no accounts.
  • No analytics, advertising or tracking, and no third-party requests from the page (fonts, scripts and images are all local).
  • The application server logs only internal error messages and one start-up line, not scanned addresses or visitor IP addresses.

Hosting providers

The site is delivered through Cloudflare (a Worker that passes your IP address on to the backend so the limits above apply per visitor) and the scanning backend runs on Render. Like any host, they process connection data (such as IP addresses and request metadata) to run and secure their services, under their own policies. A passive scan is a GET request, so the address you enter is part of the request URL and can appear in their request logs: Cloudflare and Render.

Sites you scan

A scan sends ordinary web requests to the address you entered, from our hosting provider's network, so they can appear in that site's logs. Scans are passive by default. Active checks (for example looking for exposed /.git/ or /.env files) run only after the domain owner proves control with a DNS TXT record. Only scan sites you own or are allowed to test.

Legal basis and your rights

Processing is based on the legitimate interest of operating and protecting the service. Nothing is retained beyond the minutes described above, so there is normally nothing to access or delete. If you are in the EU you may also complain to your data protection authority (in Estonia: Andmekaitse Inspektsioon).
