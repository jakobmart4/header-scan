# header-scan UI: design + DOM contract

Chosen direction: **editorial-light** (dir-editorial-light.md), warm paper + ink, one ink-blue accent, status trio reserved for status.
Scores (1-5: clarity / a11y-contrast / pure-CSS feasibility / delight): editorial 5/5/4/3, glass 4/3/4/5 (warn mark 2.6:1, blue-for-pass, blur cost), terminal 4/4/4/4 (glow + scanlines gimmicky, mono-heavy).
Grafts: neon's table heat-grid (real `<table>`, not clickable, more accessible), neon/glass `data-state` on `#results`, glass's `--i` stagger, neon's masked-sweep idea NOT used (donut uses registered `--a/--b`).
All contrast ratios for the tokens below were verified with a WCAG script (text >= 4.8:1 everywhere, `--edge` >= 3.6:1).

## Build
`node scripts/build-ui.mjs` (npm `build:ui`) reads `ui/src/index.template.html`, replaces `<!--@STYLE-->` with `<style>` + the CSS files concatenated in THIS order, and `<!--@SCRIPT-->` with `<script>` + app.js, writes `public/index.html` (deterministic, LF, no minify, fail if a part contains `</style` / `</script`, or if the output contains `style="`/` on[a-z]+=`/`innerHTML`).
Order: `tokens.css, base.css, layout.css, gauge.css, charts.css, findings.css, panels.css` (all in `ui/src/`; later files may override earlier only inside their own components).
Ownership (edit ONLY your files): A tokens/base/layout, B gauge, C charts, D findings, E panels, F app.js + scripts/build-ui.mjs + package.json `build:ui`. The template + this file are frozen.
Never touch: server.js, lib/, functions/. Only `test/api.test.js` line-56 style checks exist (no innerHTML in output) and must keep passing.

## Motion rules (everybody)
1. Animate only transform, opacity and `--p --gn --a --b`. Never width/height/top/box-shadow.
2. Base CSS IS the final state. Keyframes define only the `from` side; attach them ONLY under `#results[data-state="done"] <component>` with `animation-fill-mode: backwards`. Then no-@property, no-animation and reduced-motion all show the finished picture.
3. Replay: F sets `data-state="loading"`, forces a reflow, then `"done"`, so animations restart on every scan.
4. Choreography (delay = base + `var(--i,0)` * step, cap via `min(var(--i,0),10)`): scorecard 0ms/reveal; gauges 100ms/draw 900ms (ring and count-up in ONE keyframe so they agree); category rows 250ms + i*var(--step); donut 300ms/draw; heat cells 400ms + col*25ms (fade only); findings 500ms + min(i,10)*30ms, translateY(8px)+opacity. Total < 1.6s, nothing loops after completion (only loading states loop).
5. A owns the reduced-motion catch-all: `@media (prefers-reduced-motion: reduce){*,*::before,*::after{animation:none!important;transition:none!important;scroll-behavior:auto!important}}`. Loading loops (E) additionally become static stripes there.
6. Progressive enhancement: `@supports selector(:has(*))`, `@supports selector(::details-content)`, `html.cp` (JS adds it iff `CSS.registerProperty` exists; B gates count-up on it) with static fallbacks. `@media (forced-colors:active)`: A adds borders, B/C drop masks.
7. A11y: `:focus-visible{outline:3px solid var(--accent);outline-offset:2px}` on everything (radios: on the following label, see below); targets >= 44px on <= 640px; status is never color-only (glyph + word + number always text).

## Global state and JS-set custom properties
- `#app[data-busy="true|false"]`: true while any request is in flight (E: `#loadbar` sweeps when true; A: nothing).
- `#results[data-state="idle|loading|done|error"]` + `aria-busy` (true only while loading). E owns visibility: idle = all children hidden; loading = `#skeleton` only; done = `#report` only; error = `#error-box` only. `#results` keeps `min-height` via `#skeleton`; skeleton boxes use the same sizes as the final boxes (no layout shift).
- Status text: `#status`, `#verify-msg`: `data-tone="muted|ok|err"` (A colors them). `#toast[data-show="true|false"][data-tone="ok|err"]` (E), F shows it 2.5s for copy feedback.
- JS sets ONLY via `el.style.setProperty(name, String(Number))` (clamped, unitless), `classList`, `dataset`, `aria-*`, `textContent`, `hidden`, `disabled`:
  `--score` (0-100 int) on `.gauge`; `--i` (int) on `.crow`, `.cat`, `.fnd`; `--n` (int) on `.seg`, `.sev`; `--a`,`--b` (0-100 number, 1 decimal) on `#donut`; `--k` (0-1, 2 decimals) on `td.hc`.
- Grade band `data-g="pass|warn|fail|skip"` on `.gauge` and `.crow`: A+/A/B pass, C/D warn, E/F fail, N/A skip (categories: score >= 80 pass, >= 55 warn, else fail, null skip). `--c` (ring/segment color) is set by each component's CSS from `data-g`: `pass var(--pass) / warn var(--warn) / fail var(--fail) / skip var(--skip)`.
- `[data-s="pass|warn|fail|info|skipped"]` on `.pill .chip .lg .seg .fnd` selects status colors: `color: var(--<s>); background: var(--<s>-bg)` (skipped uses `--skip`).
